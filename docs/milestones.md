- [ ] **Python 위젯** — 임베디드 파이썬 인터프리터, REPL + 스크립트 실행
- [ ] **C# 위젯** — Roslyn 기반 스크립트 실행

### 시스템 모니터링 (Windows)

- [ ] **하드웨어 모니터링** — CPU/GPU/RAM/온도 (LibreHardwareMonitor)
- [ ] **시스템 정보** — OS, 사용자, 네트워크 인터페이스
- [ ] **프로세스 모니터링** — 실행 중 프로세스 목록 + kill
- [ ] **서비스 모니터링** — Windows 서비스 상태/시작/중지
- [ ] **이벤트 로그 모니터링** — Windows Event Log 조회
- [ ] **로그 파일 모니터링** — tail -f, grep, highlight

### 통신 / 데이터

- [ ] **소켓 위젯** — TCP/UDP 클라이언트/서버
- [ ] **시리얼포트 위젯** — COM 포트 송수신
- [ ] **PLC 위젯** — Modbus / Siemens S7 등 산업 프로토콜
- [ ] **챗GPT 위젯** — OpenAI API 연동 대화창
- [ ] **차트 위젯** — 실시간 데이터 시각화 (LiveCharts2 / OxyPlot)

### UI / 입력

- [ ] **Windows 위젯** — Windows 11 위젯 시스템 연동
- [ ] **버튼 위젯** — 커스텀 액션 바인딩
- [ ] **토글 위젯** — ON/OFF 상태
- [ ] **상태 위젯** — 2-state / 3-state 램프
- [ ] **텍스트 위젯** — 정적 라벨
